DISPLAY POWER CONTROL - HARDWARE TEST PASSED
The OSOYOO HDMI35 V2.0 returned malformed DDC/CI replies at the default 97.5 kHz
HDMI control clock. Setting HDMI-A-1's control clock to 50 kHz restored communication.
The user confirmed the backlight went completely off and a stylus tap woke it.
Linux also recorded the physical touch event while suspended, and the monitor
reported D6=3 (suspend) followed by D6=1 (on). Mumble remained active during that test.
The console uses these working DDC settings for its 60-second inactivity timer.
The installed timer was verified: it automatically reached monitor suspend state
after 60 seconds, while Mumble's process ID remained unchanged.
If DDC control ever fails, status stays visible instead of drawing a lit black screen.
This changes only the HDMI control bus, not display resolution or the GPIO battery bus.
Boot overlay: /boot/firmware/overlays/halow-ddc-slow.dtbo
Boot config rollback: /boot/firmware/config.txt.before-halow-ddc-clock-test

PISUGAR S PLUS
This model cannot report battery percentage or actual charging current/state.
Auto switch was confirmed ON. GPIO3 is used to display external charger connected
or disconnected. This does not prove that the battery is actively charging.
Live Pi undervoltage status is displayed independently.
The console now labels these as "Battery %: unsupported (S Plus)" and "PiSugar input".
A real percentage requires an added battery sensor or a reporting battery board.

FIRST BOOT
1. With the Pi powered off, return the SD card to the Pi.
2. Connect Ethernet between the Pi and HT-H7608 router.
3. Leave the OSOYOO screen connected to HDMI and GPIO.
4. For setup verification, connect the Pi USB-C to this PC using the data cable.
5. Power on and allow several minutes, including an automatic reboot.
   Packages are on the card; no internet connection is needed for installation.
6. Tell Codex when it has booted so the real hardware and network can be tested.

NORMAL USE
Mumble starts automatically and restarts if its process fails.
The Pi boots to a large-text console instead of the desktop.
Display: 640x480 with Terminus Bold 16x32 font.
Tap to cycle Status / Server log / Processes.
After 60 seconds without input the monitor suspends and turns its backlight off.
Tap firmly with the stylus to wake; further taps cycle through the status pages.
The Pi, Ethernet, GPIO touch controller and Mumble continue running.
DDC power control is checked once at startup; otherwise timeout is disabled.
Physical backlight suspend and touch wake were confirmed by the user.
